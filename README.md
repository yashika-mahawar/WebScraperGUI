# Task 6: Interactive Web Scraping Application

## Project Title

### SmartScrape Pro – Interactive Web Scraper in Java

---

## Description

This project is developed as part of the Cognifyz Internship Program.

SmartScrape Pro is a Java Swing based Interactive Web Scraping Application that fetches real-time quote data from websites and presents it in a user-friendly graphical interface. The application uses the Jsoup library to connect with websites, extract HTML data, and display the scraped information dynamically in a structured table format.

The project demonstrates the integration of GUI development and web scraping concepts using Java.

---

# Objective

The main objective of this project is to:

* Fetch data from a website using web scraping techniques
* Present the extracted data in an interactive GUI
* Provide a clean and user-friendly interface
* Implement search and export functionalities

---

* Java Swing
* Jsoup Library

# How the Project Works

1. The user enters a website URL.
2. The application connects to the website using Jsoup.
3. HTML content is fetched from the webpage.
4. Quotes and author names are extracted dynamically.
5. Extracted data is displayed in a JTable format.
6. Users can search quotes by author name.
7. Users can export the scraped data into a text file.

---
